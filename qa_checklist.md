# QA Validation Checklist

Before seeking Engineer Approval, the AI must check the following:

- [ ] Does the report follow AS1726 terminology exactly?
- [ ] Are all depths continuous with no overlaps or gaps?
- [ ] Have all test results been verified against raw data (no invented results)?
- [ ] Are bearing capacity recommendations correctly flagged with uncertainty if ambiguous?
- [ ] Has the draft been cross-referenced with past templates/examples in RAG?
